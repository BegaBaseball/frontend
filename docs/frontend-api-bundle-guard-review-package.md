## Changes Verified

- `/matches/range` wire typing, paging normalization, and public GET request construction are centralized in `matchRangeClient`.
- `home`, `prediction`, and `predictionRange` load `matchRangeClient` through call-time dynamic imports, avoiding static route preload for the match range helper.
- `privateClient`, `publicClient`, and auth reissue now share URL construction, response parsing, timeout/abort handling, JSON body/header handling, and reissue request construction through `httpClientCore`/`authReissue`.
- Public API function names, endpoint paths, query parameter names, mapper behavior, and error handling remain unchanged.
- Bundle guard now allows only tiny raw byte drift: `min(64 bytes, maxBytes * 0.5%)`.
- Bundle guard reports include `overageBytes`, `graceBytes`, `graceRatio`, and `graceLimitBytes`.
